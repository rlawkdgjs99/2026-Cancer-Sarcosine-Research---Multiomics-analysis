# Reproducibility contract

## General rules

1. Run each module from its own directory unless its README states otherwise.
2. Obtain the public inputs from the accession or DOI listed in `DATASETS.md`.
3. Preserve sample identifiers and verify one-to-one alignment before modeling.
4. Do not replace recorded gene-set versions, group definitions, covariates, or multiplicity families without labeling the run as a sensitivity analysis.
5. Treat generated figures as views of the saved tables; statistical claims should be checked against the tables and verification logs.

## Shared immune-axis discovery

The public release includes the exact-set comparison and final-narrowing result tables. Large expression matrices and the full 4,649-row joined pathway table are intentionally omitted; they are regenerated by the scripts from the cohort inputs. The final analysis used MSigDB 2026.1.Hs and 5,000 bootstrap replicates per route, direction, model, and cohort.

The expected discovery cohort sizes are 73 pretreatment melanoma tumors and 100 matched ccRCC tumors. The primary claims are exact-pathway replication and downstream covariance. A complete exposure-linked serial pathway is not an expected positive control.

## TCGA NSCLC validation

The validation module downloads UCSC Xena TCGA LUNG resources, retains LUAD/LUSC primary tumors, computes the SARDH/PIPOX degradation score, and evaluates the four prespecified pathways. The public verification script checks sample identity, score reconstruction, pathway-result matching, gene-disjointness, model refits, and output integrity.

The selected tables and compact public-release table-audit log are supplied. The full verification script runs after the omitted source matrices and sample-level intermediate table have been regenerated. A fresh end-to-end run therefore requires network access and the listed R/Bioconductor packages.

## Software

Every final analysis module includes a `sessionInfo.txt` or equivalent session snapshot when one was produced in the original run. Package availability and remote database versions may change; use the recorded session information and gene-set version when exact numerical reproduction is required.

## Verification before reuse

- Parse all R and Python scripts.
- Confirm no sample identifiers are duplicated after the intended biological-unit collapse.
- Recompute exposure scores from their component genes or metabolite field.
- Refit exported model coefficients from sample-level tables where those tables are supplied.
- Recalculate file hashes for every local input and compare them with the public manifest.
- Review the module-specific interpretation boundary before copying text into a manuscript.
