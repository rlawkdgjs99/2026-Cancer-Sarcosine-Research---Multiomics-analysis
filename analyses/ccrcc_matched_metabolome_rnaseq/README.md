# Matched ccRCC tumor metabolome–RNA-seq analysis

This module analyzes 100 ccRCC tumors with matched untargeted metabolomics and bulk RNA-seq from Zenodo record 8063124 (source article: DOI 10.1038/s41588-024-01662-5).

The primary contrast is measured tumor Sarcosine-Low versus High using the within-cohort median. Scripts cover input auditing, matching, primary GSEA, immune deconvolution, TF inference, continuous and quartile sensitivities, and final pathway narrowing.

Run the scripts in numeric order. Source matrices are not included. The metabolite values are normalized intensities and must not be described as absolute concentrations.
