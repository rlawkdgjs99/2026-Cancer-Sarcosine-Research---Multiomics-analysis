# ccRCC paired tumor–normal metabolomics

This module tests sarcosine abundance in 138 matched ccRCC tumor/normal pairs using the Hakimi et al. supplementary metabolomics workbook (`1-s2.0-S1535610815004687-mmc2.xlsx`; associated transcriptomic accession GSE74734).

Run `R_scripts/01_sarcosine_tumor_vs_normal.R` from a directory containing the workbook. The script writes statistics and plots to `Outputs/`. Raw and supplementary data are not redistributed.
