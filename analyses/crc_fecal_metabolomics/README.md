# CRC fecal metabolomics

This module reproduces the CRC-versus-healthy fecal-metabolomics analysis from MetaboLights MTBLS10232, including sarcosine, differential tables, volcano summaries, and quality-control outputs.

Run `R_scripts/05_characterize_matrices.R`, `13_consolidated_regeneration.R`, and `14_dissertation_plots.R` in numeric order from the analysis-data root. Required inputs are the positive- and negative-mode MAF tables, merged metadata, and the source-publication supplementary table used for replication. Raw data are not included.
